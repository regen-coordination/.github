# Regen Coordination Security Policy

Use this policy to report vulnerabilities in Regen Coordination repositories that do not publish their own security policy. Follow the affected repository's policy when one is available.

## Report a vulnerability privately

Email [regencoordination@proton.me](mailto:regencoordination@proton.me) with the subject "Security report: [repository name]".

Include, where available:

- The affected repository, component, and version or commit.
- A description of the issue and its potential impact.
- Steps to reproduce using synthetic or redacted examples.
- Relevant logs or other supporting evidence with secrets and personal data removed.

Keep vulnerability details out of public issues and pull requests. Do not include credentials, private keys, or real user records in a report.

## Supported versions

Each project defines its own supported versions and maintenance scope. Check its README, release notes, and security policy. If support is unclear, ask through the private reporting contact above.

## Assessment and disclosure

Maintainers assess the report, coordinate any remediation, and discuss appropriate disclosure with the reporter. The affected project's maintainers determine release and remediation plans.

No organization-wide response deadline, security bounty, or payment is promised by this policy. Any project-specific commitments must be published or agreed separately.

## Other questions

For ordinary bugs and project questions, use the routes in [Support](https://github.com/regen-coordination/.github/blob/main/SUPPORT.md). For harassment or other community conduct concerns, use the [Code of Conduct](https://github.com/regen-coordination/.github/blob/main/CODE_OF_CONDUCT.md).
