# Regen Coordination GitHub Governance

This guide explains where to propose repository changes and find the relevant decision process. Each project retains its own scope, maintainer responsibilities, and governance requirements.

## Project changes

Propose work in the repository that owns it. Read that project's README and contributor guidance, describe the need and intended outcome, and link the relevant sources or discussions.

Project maintainers review and merge repository contributions under that project's rules. Follow its required review, testing, and publication steps.

## Shared organization guidance

Changes to the organization profile, shared policies, and default issue templates belong in a [pull request to this repository](https://github.com/regen-coordination/.github/pulls). Explain the proposed change and which contributors or projects it affects.

Shared contribution guidance should remain useful across research, knowledge, documentation, design, software, and coordination work. Put project-specific technical standards in the owning repository.

## Network-level proposals

Start with the [Coordination OS governance documentation](https://github.com/regen-coordination/regen-coordination-os/blob/main/README.md#governance) for the network's decision process. Use [Coordination OS issues](https://github.com/regen-coordination/regen-coordination-os/issues) to propose cross-project coordination work.

Identify the affected projects, expected outcome, dependencies, proposed responsibilities, and any funding or publication decisions needed. Seek review from the people responsible for the affected work and record the resulting decision in the relevant project documentation, linked to the discussion.

A repository merge does not by itself authorize spending, external publication, or changes to another project's policies. Follow the decision process of the project or network responsible for that action.

## Private concerns

Use the private reporting routes in the [Code of Conduct](https://github.com/regen-coordination/.github/blob/main/CODE_OF_CONDUCT.md) and [Security policy](https://github.com/regen-coordination/.github/blob/main/SECURITY.md) for sensitive reports.
