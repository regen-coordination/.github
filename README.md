# Regen Coordination on GitHub

Regen Coordination brings people and projects together to strengthen coordination across regenerative communities. Our shared work connects knowledge, practical tools, and organizational learning so communities can build on one another's experience.

This repository holds our [organization profile](profile/README.md) and shared contribution guidance.

## Find a project

- [Regen Knowledge Commons](https://github.com/regen-coordination/knowledge-commons): shared knowledge infrastructure, commoning documentation, and Geo tooling.
- [Regen Toolkit](https://github.com/regen-coordination/regen-toolkit): practical learning resources for regenerative communities using web3 tools.
- [Regen Coordination OS](https://github.com/regen-coordination/regen-coordination-os): organizational memory, coordination workflows, shared skills, and network knowledge.

The [project map](https://github.com/regen-coordination/knowledge-commons/blob/main/docs/MAP.md) explains how these projects relate. Each project maintains its own scope, working status, and contribution requirements.

## Shared guidance

- [Contributing](CONTRIBUTING.md): ways to help and how to submit work.
- [Code of Conduct](CODE_OF_CONDUCT.md): community expectations and private incident reporting.
- [Security](SECURITY.md): private vulnerability reporting.
- [Support](SUPPORT.md): project questions and help.
- [Governance](GOVERNANCE.md): where to propose changes and find decision processes.

For changes to these shared documents, open a [pull request in this repository](https://github.com/regen-coordination/.github/pulls). For work on a project, use that project's repository.

## How these defaults work

GitHub uses the supported community files in this public `.github` repository when another repository in the organization does not define its own file of that type. A repository's own valid issue templates or issue-template configuration override the entire shared issue-template set.

The shared [issue templates](.github/ISSUE_TEMPLATE) cover bugs, proposals, knowledge corrections, and coordination tasks. Project-specific technical requirements belong in the owning repository. Governance guidance is linked here for reference; GitHub does not distribute it as a default community file. Licenses also remain specific to each repository.

See [GitHub's default community file documentation](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for supported files and precedence.

## Funding

No organization-wide sponsorship destination is configured in this repository. When funding destinations are approved for Regen Coordination, add `.github/FUNDING.yml` using [GitHub's supported configuration](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/displaying-a-sponsor-button-in-your-repository).

Funded contribution work requires a separate agreement as described in the [contribution guide](CONTRIBUTING.md).
