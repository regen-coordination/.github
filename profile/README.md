# Regen Coordination

Regen Coordination brings people and projects together to improve how regenerative communities share knowledge, build useful tools, and learn from practice. The work involves collaborators across GreenPill Network, ReFi DAO, Bloom Network, and the wider regenerative and public-goods ecosystem.

## Find the work

| Project | Where to start |
| --- | --- |
| [Regen Knowledge Commons](https://github.com/regen-coordination/knowledge-commons) | Knowledge-commoning documentation, Geo tools, and developing ingestion and review approaches. |
| [Regen Toolkit](https://github.com/regen-coordination/regen-toolkit) | Public, practical learning resources for regenerative communities using web3 tools. |
| [Regen Coordination OS](https://github.com/regen-coordination/regen-coordination-os) | Organizational memory, coordination workflows, shared skills, and network knowledge. |

See the [project map](https://github.com/regen-coordination/knowledge-commons/blob/main/docs/MAP.md) for their relationships, relevant frameworks, and earlier research and implementation work.

Each repository has its own scope and working status. To suggest a correction or contribute, start with the relevant repository's documentation, issues, or pull requests. Publication and review requirements for knowledge or Geo edits remain separate from ordinary GitHub documentation changes.
